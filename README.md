# StudyPoint 📚

StudyPoint is an Android educational app built with Kotlin.

## Features
-  Notes
-  MCQs
-  Past Papers
- Chapter-wise Study Material
- Firebase Authentication
- Simple and Modern UI

## Technology
- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
